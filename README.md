Kota Joe. Modern Street Food Website

1. Project Overview

This project is part of the Web Development POE (Part 3). It is a website of features and interactive for Kota Joe, a modern roadhouse and street food brand. The website gives users an experience with an online menu that can be searched live and sorted by price. It also has forms for signing in processing credit card orders, a gallery lightbox and a map showing the branch location.

2. Features & Functionality

Interactive UI Elements:

Gallery lightbox modal that shows full-size product and branch pictures when clicked

scrolling navigation through all page sections

Dynamic Content & Search:

Menu search engine and price sorting dropdown (Low to High / High to Low)

Site-wide header search filter that highlights content dynamically

Integrations & Accessibility:

Embedded Google Maps for the Edenvale branch

Floating WhatsApp chat integration for instant customer support and orders.

Mobile-responsive design and optimized image alt-text

3. Technology Stack

HTML5 (Semantic markup, sections accessibility attributes)

CSS3 (Custom properties/variables Flexbox, Grid layout, dark theme styling)

JavaScript (ES6+) (DOM manipulation, event listeners, search filtering, client-side validation logic)

FontAwesome & Google Font for typography and icons.
